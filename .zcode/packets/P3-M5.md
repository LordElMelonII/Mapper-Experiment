## Context (verbatim, with IDs)

**D94 (EXECUTION-PLAN §1, R25 — the ruling):** Blocking the bridge blocks the hub, not its ten arcs. `ChatMapOverlay.nodeBlocked: Record<nodeId, reason>` mirrors the arc blocks (D20 spirit: excluded from routing, visible to the prompt); facade `setNodeBlocked(nodeId, reason?)` mirroring `setBlocked` — add path gated to the saved plane (`savedNodeIds` ∪ overlay user nodes, D75's runtime clause), lift unconditional, non-empty reason. **A blocked node is impassable as a destination and as an intermediate stop, but may serve as a route's origin** (new convention **C34**; owner pick on the pin-on-bridge edge — the party can always leave somewhere they already are); routing to or through it returns unreachable naming the block; the node stays drawn, marked. Blocked nodes surface in the snapshot's blocked listing like arcs.

**C34 (CORE.md §5 — the new convention):** A blocked node is impassable as a route destination and as an intermediate stop: routing to or through it returns unreachable with the block named, the node-level mirror of C2's blocked-arc rule. The origin is exempt — a route may start at a blocked node (the party can always leave somewhere they already are). The block is overlay state carrying a non-empty reason (`nodeBlocked`, mirroring the arc `blocked` map); the node stays drawn with its block marker, and the reason surfaces in the snapshot's blocked listing like an arc's.

**C2 (CORE.md §3, the arc precedent):** Blocked ≠ hidden. A blocked arc is excluded from routing (infinite cost) but remains in the snapshot with its reason, so the LLM knows *why* a route is unavailable.

**C17:** No finite path ⇒ `ok: false` plus a human-readable reason (disconnected, or all candidate arcs blocked/disallowed). The value ∞ never appears in any output.

**C30:** Validators run before any graph change; errors are field-precise and collected. **F50:** malformed or future-version data is rejected with precise messages, never half-loaded.

**The setBlocked precedent (src/core/facade.ts:576–614, verbatim — MIRROR THIS at every semantic seam):**

```ts
    setBlocked: (edgeId, reason) => {
      ensureFresh(); // C8 — keeps the no-map invariant below uniform with the other §9 commands
      const { overlay, effective } = state;
      if (overlay === null || effective === null) throw new Error('[TravelMapper] no map loaded');
      if (reason !== undefined) {
        // A-014 (D75 amendment): the ADD path writes an overlay key, so it may
        // only reference an edge the SAVED plane knows (savedEdgeIds ∪
        // overlay user edges) — a key absent from the saved library would make
        // validateOverlay refuse the WHOLE overlay at the next load (F50).
        // An unsaved editor arc is refused exactly like an unknown one (C30
        // field-precise); the LIFT path below never binds and stays
        // unconditional.
        if (!state.savedEdgeIds.has(edgeId) && !overlay.userEdges.some((e) => e.id === edgeId)) {
          throw new Error(`[TravelMapper] setBlocked: unknown edge id '${edgeId}' (unsaved — save the map first)`);
        }
        // C30/F50: a runtime caller can lie about the typed optional — validate
        // before mutating (setStatusNote precedent). An empty string is neither
        // a reason nor a lift: refusing it never silently clears a block.
        // Whitespace-only is the same defect (P2 M2 verifier finding 3 — a
        // Phase 4 host caller could otherwise persist a blank-looking reason
        // that reaches prompts verbatim as C2's payload). Valid strings are
        // stored verbatim, untrimmed — the reason is the author's payload.
        if (typeof reason !== 'string' || reason.trim().length === 0) {
          throw new Error(
            `[TravelMapper] setBlocked: reason must be a non-empty string or undefined (got '${String(reason)}')`,
          );
        }
        overlay.blocked[edgeId] = reason; // D20: chat-scoped block — adds or restates only
      } else {
        // Lift: an UNCONDITIONAL delete of the overlay entry (A-014 — the lift
        // path never binds state, so the saved-plane gate does not apply; a
        // no-op on an unknown/stale key is harmless). C2/A-002 — the overlay
        // can only add a block, never lift one, so a library-level block
        // survives this delete (a silent no-op there); the next rebuild
        // re-merges the union.
        delete overlay.blocked[edgeId];
      }
      state.stale = true; // C8 — the next query's ensureFresh picks the change up
    },
```
